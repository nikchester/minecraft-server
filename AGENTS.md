# Agent guidance

## Source of truth for work items

- Use open GitHub Issues in `nikchester/minecraft-server` as the source of truth for current tasks, scope, and priority.
- Do not use `PLAN.md` to identify or prioritize current work; it is historical and may be outdated.
- Before prioritizing tasks, fetch the open issues and inspect issue descriptions and labels. Add the matching GitHub priority label (`priority:critical`, `priority:high`, `priority:medium`, or `priority:low`) only to issues that do not already have a priority label.
- Preserve existing priority labels unless the user explicitly asks to change them.
